# 500 条 Benchmark 阶段性验证报告

## Executive Summary（结论摘要）

- **系统已基本跑通新版 Benchmark。** 500 条输入中，474 条成功召回节点，468 条获得图谱路径；同时具备路径且 LLM 调用成功的样本为 462 条，完整链路覆盖率为 **92.4%**。
- **风格和车型预测具备较好的候选命中能力。** 在只评判非空 `expected`、候选命中一个即算通过的口径下，风格命中率为 **90.0%**，车型命中率为 **77.0%**；只考察风格和车型时，case 通过率为 **79.1%**。
- **Top 25 Schema 足以覆盖当前绝大多数路径形态。** 新方法覆盖 458/500 条，结构覆盖率为 **91.6%**，比旧方法的 83.4% 提升 8.2 个百分点。
- **当前主要问题集中在级别字段。** LLM 原始响应中有 188 条给出级别，但最终仅保留 4 条，导致最终级别命中率只有 **0.5%**。级别链路修复前，不建议用包含级别的综合指标评价系统效果。

**阶段性判断：召回、路径、风格预测、车型预测和 Schema 覆盖已经具备继续推进条件；级别处理需要优先修复后再验收。**

本次工作已完成 500 条离线召回、Neo4j 路径查询优化、evidence 生成、LLM 并发预测、路径与 Schema 反转、Top-N Schema 选择及效果复算。

## 1. 新版 500 条数据已经基本跑通

| 环节 | 成功样本 | 占 500 条比例 | 相对上一环节 |
|---|---:|---:|---:|
| Benchmark 输入 | 500 | 100.0% | — |
| 至少召回一个节点 | 474 | 94.8% | 94.8% |
| 生成图谱路径 | 468 | 93.6% | 98.7%（相对召回成功） |
| LLM 调用成功 | 468 | 93.6% | 98.7%（相对 474 次调用） |
| 同时有路径且 LLM 成功 | 462 | **92.4%** | — |

当前主要损失来自三处：26 条没有达到 0.60 召回阈值，6 条召回后没有形成路径，另有 6 条因网络连接异常导致 LLM 调用失败。

**结论：** 当前系统可以稳定处理绝大多数新版输入，链路覆盖已经超过九成；下一步重点不再是“能否运行”，而是提升输出质量并处理失败样本。

### 召回阈值对覆盖率影响明显

| 阈值 | 至少召回一个节点 | 召回满 20 个 | 节点引用数 | 平均节点数/样本 |
|---:|---:|---:|---:|---:|
| 0.50 | 500（100.0%） | 500 | 10,000 | 20.00 |
| 0.60 | 474（94.8%） | 334 | 7,804 | 15.61 |
| 0.70 | 99（19.8%） | 4 | 342 | 0.68 |

0.60 在过滤低分节点的同时保留了 94.8% 的输入；提高到 0.70 后覆盖率会降至 19.8%，因此当前继续使用 0.60 更合适。

### 路径和 LLM 运行数据

| 项目 | 结果 |
|---|---:|
| 阈值后节点引用 / 不同节点 | 7,804 / 1,411 |
| 总路径数 / 有路径样本 | 28,868 / 468 |
| 平均路径数（仅有路径样本） | 61.7 |
| 有风格终点 / 有车型终点 | 463 / 461 |
| 同时有风格和车型终点 | 461 |

| 总 token 数 | 2,976,117 |

路径后处理将每条样本的风格终点和车型终点分别限制在最多两个，因此进入预测阶段的候选数量整体受控。

## 2. 风格和车型候选命中率分别为 90.0% 和 77.0%

本次采用 Top-N 宽松命中口径：

- 某字段的 `expected` 为空时，该字段不参与评判；
- `expected` 非空时，预测结果只要与其至少有一个共同标签，就算命中；
- 额外预测的候选本次不扣分；
- 各尺寸 SUV、MPV 统一到 SUV、MPV 大类后再比较。

例如 `expected=[科技]`、`predicted=[科技, 豪华]`，因为命中“科技”，该字段记为通过。

| 评估指标 | 通过数 | 评估样本数 | 命中率 |
|---|---:|---:|---:|
| 风格字段 | 270 | 300 | **90.0%** |
| 车型字段 | 231 | 300 | **77.0%** |
| 只评风格和车型的 case | 340 | 430 | **79.1%** |
| 评估全部非空字段的 case | 203 | 470 | 43.2% |

“只评风格和车型的 case”要求一条样本中非空的风格、车型字段全部命中。最后一项还加入了级别，因此被当前级别问题明显拉低。

**结论：** 风格预测效果较好，车型预测已具备可用基础但仍有提升空间。79.1% 表示正确候选是否被系统覆盖，不代表系统没有输出额外候选。

### 标签粒度统一对车型结果影响较大

| 指标 | 直接按标签比较 | SUV/MPV 大类统一后 |
|---|---:|---:|
| 车型字段命中率 | 138/300（46.0%） | 231/300（77.0%） |
| 风格+车型 case 通过率 | 252/430（58.6%） | 340/430（79.1%） |

差异主要来自 Benchmark 使用 `SUV`、`MPV` 大类，而系统输出 `中型SUV`、`中大型MPV` 等细分类别。因此，甲方若关注车型大类是否正确，应采用统一后的 77.0%；若要求输出标签逐字一致，则当前结果为 46.0%。

### 具体输入和模糊输入各有不同优势

| 输入类型 | 风格命中率 | 车型命中率 | 风格+车型 case 通过率 |
|---|---:|---:|---:|
| specific（250 条） | 128/150（85.3%） | 129/150（86.0%） | 175/215（81.4%） |
| vague（250 条） | 142/150（94.7%） | 102/150（68.0%） | 165/215（76.7%） |

模糊输入的风格命中更高，但车型命中明显低于具体输入，说明模糊描述更容易支持风格判断，却不足以稳定确定车型。

## 3. 级别结果在后处理阶段大量丢失

| 级别处理阶段 | 输出级别样本数 | 命中数 | 在 210 条中的命中率 |
|---|---:|---:|---:|
| LLM 原始响应 | 188 | 188 | 89.5% |
| 最终预测文件 | 4 | 1 | 0.5% |
| 原始有值但最终消失 | 184 | — | — |

当前程序在 LLM 给出级别后，又调用图谱分布方法重新推断；如果图谱推断返回空值，LLM 已经给出的级别也会被覆盖。因此，最终 210 条需要评估级别的样本中只有 1 条命中，命中率为 0.5%。

离线复算显示：如果暂时保留 LLM 原始级别，其他预测保持不变，全部非空字段的 case 通过率可从 43.2% 提升到 **78.3%**。该数字用于说明问题影响范围，修复后仍需重新运行才能作为正式结果。

不同任务组合受到的影响如下：

| Benchmark 任务类型 | 当前通过率 | 保留 LLM 原始级别后的参考通过率 |
|---|---:|---:|
| 仅风格 | 71/80（88.8%） | 71/80（88.8%） |
| 仅车型 | 52/80（65.0%） | 52/80（65.0%） |
| 风格+车型 | 79/100（79.0%） | 79/100（79.0%） |
| 仅级别 | 1/40（2.5%） | 33/40（82.5%） |
| 风格+级别 | 0/50（0.0%） | 44/50（88.0%） |
| 车型+级别 | 0/50（0.0%） | 37/50（74.0%） |
| 风格+车型+级别 | 0/70（0.0%） | 52/70（74.3%） |
| 三个字段均不指定（none） | 不参与评判（30 条） | 不参与评判（30 条） |

前三类不依赖级别，因此修复前后不变；后四类都包含级别，当前结果几乎全部被级别丢失拖至不通过。

**结论：** 当前级别低分主要是链路处理问题，应先修复数据覆盖逻辑，再讨论级别模型效果。

## 4. Top 25 Schema 已覆盖 91.6% 的全部样本

Schema 覆盖只检查一条样本是否同时存在风格路径和车型路径，不使用 `expected`，因此它评价的是路径模板覆盖能力，不是预测准确率。

| Schema 数量 N | 旧方法覆盖率 | 新方法覆盖率 |
|---:|---:|---:|
| 3 | 63.6% | 64.2% |
| 5 | 63.8% | 74.6% |
| 10 | 78.2% | 85.6% |
| 15 | 78.8% | 88.6% |
| 20 | 82.6% | 90.6% |
| 25 | 83.4% | **91.6%** |
| 30 | 84.8% | 92.0% |
| 50 | 88.6% | 92.2% |

新方法不再只选择出现次数最多的 Schema，而是优先选择能够补充新样本覆盖的 Schema。Top 25 由 9 个风格 Schema 和 16 个车型 Schema 组成，共覆盖 458 条；增加到 50 个 Schema 也只多覆盖 3 条。

**结论：** N=25 是当前较合适的规模，继续增加 Schema 的收益已经很小。后续应固定这 25 个 Schema，在独立数据上验证泛化覆盖能力。

## 5. 建议下一步优先完成两项工作

1. **先修复级别覆盖逻辑。** 明确 LLM 显式级别与图谱推断级别的优先级，避免正确或有效的级别被空值覆盖；修复后重新运行 500 条 predict。
2. **补充失败重试和独立验证。** 对 6 条网络失败增加有限重试，同时用独立样本验证 Top 25 Schema，避免只在本批数据上得到较高覆盖率。

风格和车型可以继续沿用本次宽松命中率作为“候选覆盖”指标。如果甲方还关心多预测问题，应另行增加 Precision 指标，不应与本次命中率混为同一个指标。
