# 8.27 Benchmark 报告



## 1. 测试集

测试集共 500 条，全部由GPT5.6sol逐条编写，

| 维度 | 数量 |
|---|---:|
| 明确造型描述 | 250 |
| 模糊人物、场景或审美描述 | 250 |
| 无主节点预期 | 30 |
| 仅风格 | 80 |
| 仅车型 | 80 |
| 仅级别 | 40 |
| 风格 + 车型 | 100 |
| 风格 + 级别 | 50 |
| 车型 + 级别 | 50 |
| 风格 + 车型 + 级别 | 70 |

空预期字段不参与 Recall，但系统在空字段上返回候选会被单独统计为误推断。级别只在输入明确出现时设置预期，不通过车长、轴距或用户画像猜测级别。

## 3. 总体结果

- `Precision = 正确预测标签数 / 全部*预测*标签数`。预期为空时返回的标签计为 false positive。
- `Recall = 正确预测标签数 / 全部*预期*标签数`。
- 只有与人工预期枚举完全一致的标签才计为命中。

| 字段 | TP | 预测标签数 | 预期标签数 | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 风格 | 193 | 340 | 319 | 56.8% | 60.5% | 58.6% |
| 车型 | 262 | 429 | 301 | 61.1% | 87.0% | 71.8% |
| 级别 | 34 | 34 | 210 | 100.0% | 16.2% | 27.9% |
| 微平均总体 | 489 | 803 | 830 | 60.9% | 58.9% | 59.9% |

| 指标 | 结果 | 含义 |
|---|---:|---|
| 完成样例 | 500 / 500 | 500 条测试全部成功执行并生成结果，没有样例因服务或程序异常缺失。它不表示 500 条预测全部正确。 |
| 有风格或车型预期时，必需风格/车型联合命中 | 286 / 430，66.5% | 430 条至少要求判断风格或车型；其中 286 条命中了该样例要求的全部风格、车型字段。级别不参与这一行，额外候选也不扣分。 |
| 所有必需字段联合命中 | 194 / 470，41.3% | 排除 30 条三个字段均为空的样例后，470 条至少有一个预期字段；其中 194 条命中了该样例全部非空预期字段。额外候选不扣分。 |
| 澄清判断一致 | 430 / 500，86.0% | 系统判断“需要继续询问用户”或“信息已经足够”的结果，与人工设置的 `needs_clarification` 一致 430 条。 |

“所有必需字段联合命中”要求一条样例中所有非空预期字段都至少命中一个正确值，但不惩罚额外候选。该指标受级别 Recall 明显拖累。

级别 Precision 为 100% 不能单独理解为级别能力优秀：系统只返回了 34 个级别标签，全部命中，但漏掉了 176 个预期级别，表现为高 Precision、极低 Recall。级别 Recall 较低的主要原因是现有图谱没有有效关联级别标签。车型相反，Recall 较高，但额外车型候选较多，Precision 仅为 61.1%。

### 空字段误推断

| 字段 | 空预期时返回非空候选 | 比例 |
|---|---:|---:|
| 风格 | 95 / 200 | 47.5% |
| 车型 | 89 / 200 | 44.5% |
| 级别 | 0 / 290 | 0% |

30 条三个主节点均无预期的样例中，系统仅对 19 条完全保持空输出，完整克制率为 63.3%。这说明当前主要风险不是级别乱猜，而是把人口属性、一般使用场景或局部配置过度解释成风格和车型。

## 4. 分组结果

### 明确描述与模糊描述

| 输入类型 | 风格命中 | 车型命中 | 级别命中 | 必需字段联合命中 |
|---|---:|---:|---:|---:|
| 明确描述 | 87 / 150，58.0% | 135 / 150，90.0% | 17 / 105，16.2% | 96 / 235，40.9% |
| 模糊描述 | 105 / 150，70.0% | 126 / 150，84.0% | 17 / 105，16.2% | 98 / 235，41.7% |

模糊描述的风格命中高于明确描述，但结合较高的空字段误推断率看，这并不完全代表更可靠。Qwen 对人物与场景更倾向于主动补全风格，既增加命中，也增加无依据推断。

### 预期字段组合

| 预期组合 | 数量 | 所有必需字段命中 | 命中率 |
|---|---:|---:|---:|
| 仅风格 | 80 | 52 | 65.0% |
| 仅车型 | 80 | 65 | 81.3% |
| 仅级别 | 40 | 8 | 20.0% |
| 风格 + 车型 | 100 | 54 | 54.0% |
| 风格 + 级别 | 50 | 6 | 12.0% |
| 车型 + 级别 | 50 | 8 | 16.0% |
| 三者全部 | 70 | 1 | 1.4% |

三字段组合几乎无法完整命中，直接原因是当前 pipeline 对级别支持不足。该结果不应被解释为风格和车型检索完全失效。

## 5. 代表案例

### 有效结果

- `M031`：像素灯带、动态灯语、电子外后视镜，正确返回科技风格。
- `M232`：六座中央通道、低地板滑门、环抱式光带，正确返回科技 + MPV。
- `M453`：A0 级、四门独立尾箱、纯平侧围、单色车身，正确返回简约 + 三厢轿车 + A0。

### 风格漏召回

- `M032`：封闭式光滑前脸、隐藏式门把手、低风阻轮毂，预期科技，但风格为空，反而无依据返回三厢轿车。
- `M041`：竖向精密镀铬格栅、长车头、深色镜面漆，预期豪华，但没有返回风格。
- `M052`：同色封闭面板、纯平门把手、无镀铬亮条，预期简约，却返回科技。

这些案例说明科技、简约之间缺少稳定边界。

### 车型误判

- `M112`：三排独立座椅、中央通道、低地板，预期 MPV，却返回 SUV。
- `M138`：双排座舱与独立开放货台，预期皮卡，却返回 MPV。
- `M163`：行李舱与座舱完全隔离、只开启箱盖，预期三厢轿车，却返回 SUV 和 MPV。

车型总体 Recall 较高，但当结构证据没有被 Top-k 节点准确覆盖时，扩展得到的弱相关证据会压过用户明确描述。

### 空预期仍返回候选

- `M018`：“年轻人的第一辆车、预算有限”，无主节点预期，却返回简约、运动、两厢轿车和 SUV。
- `M019`：“五十岁用户、上下班使用”，无主节点预期，却返回豪华和两厢轿车。
- `M023`：“国内城市使用、一年一万公里”，无主节点预期，却返回科技和两厢轿车。

当前设计采用无条件 Top-k 向量召回，没有设置最低相似度阈值，因此无论输入与图谱知识是否足够相关，Qdrant 都会返回一个最近节点。后续流程继续基于该节点扩展和筛选，导致空预期样例仍可能产生风格或车型候选。

## 6. 总结

当前 pipeline 在 500 条 benchmark 上全部成功运行，说明向量召回、图谱证据扩展和 LLM 筛选的整体流程已经具备可用性。总体 Precision 为 60.9%，Recall 为 58.9%，F1 为 59.9%，目前可以作为汽车造型知识检索和候选发现原型，但准确率还不足以直接替代用户确认。

不同字段的表现差异较大：车型效果最好，F1 为 71.8%，说明车身结构和空间布局信息具有较强识别力；风格 F1 为 58.6%，科技与简约、豪华与商务等相近概念仍容易混淆；级别 F1 只有 27.9%，主要问题是级别目前没有有效关联上图谱，只能依照用户的清晰意图确认。

当前还存在明显的空预期误召回：在没有风格或车型预期的样例中，系统仍分别有 47.5% 和 44.5% 的概率返回候选。主要原因是 Top-1 向量查询没有设置最低相似度阈值，任何输入都会返回最近节点，低相关节点随后可能被扩展成具体风格或车型。

后续提升空间主要包括：

1. **补齐图谱关系。** 当前级别标签缺少有效关联，需要补充级别与可验证造型、车型及参数证据之间的关系，提高级别的可检索性。
2. **提高风格和车型关系质量。** 强化科技与简约、豪华与商务等相近风格的区分依据，补充车身结构与车型之间的直接证据，并清理语义宽泛或方向不准确的关系。
3. **提升节点与关系的文本质量。** 节点摘要需要准确描述可观察造型特征，关系语义需要能够直接支持推断，避免宽泛概念和低质量文本污染候选结果。
4. **优化固定路径质量。** 根据不同起点标签设计和验证高价值路径模板，提高主节点覆盖率，同时限制弱相关扩展。路径是否保留应由 benchmark 中的实际命中贡献决定，而不是只看能否连通。
